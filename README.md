# 简历小师

一个开箱即用的在线简历制作工具。编辑实时预览，支持多种模板、AI 辅助写作、导出 PDF。

## 快速开始

直接用浏览器打开即可使用，无需安装任何依赖。

```bash
# 方法一：直接双击打开
# 双击 index.html 文件即可在浏览器中运行

# 方法二：使用本地服务器（推荐，可正常使用导出 PDF 功能）
npx serve .
# 或
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 功能概览

1. **编辑简历**：左侧编辑个人信息、工作经历、教育背景、技能特长、项目经历
2. **实时预览**：右侧实时显示 A4 格式预览，可缩放、平移
3. **模板切换**：支持经典、现代、创意三种模板
4. **照片上传**：支持证件照上传，可调整位置（左侧/右侧/隐藏）和大小
5. **字体设置**：可调整正文字体、标题字体、字号、行高
6. **AI 助手**：接入大模型 API，支持 AI 生成简历内容、优化描述、诊断问题
7. **存档管理**：支持多存档本地存储
8. **导出 PDF**：一键导出标准 A4 PDF 文件

## 使用流程

### 1. 填写个人信息

左侧编辑面板包含以下栏目：

- **个人信息**：姓名、职位、电话、邮箱、地址、个人简介
- **工作经历**：可添加多条，包含公司、职位、时间、工作描述
- **教育背景**：可添加多条，包含学校、专业、学历、时间
- **技能特长**：输入技能后按回车添加，支持任意数量
- **项目经历**：可添加多条，包含项目名称、角色、描述、链接

每个栏目都可以折叠/展开，点击栏目标题即可切换。

### 2. 添加照片（可选）

1. 在"个人信息"栏目中点击"选择照片"
2. 选择证件照（JPG/PNG，建议使用标准证件照）
3. 上传后可在"照片位置"选择左侧/右侧/隐藏
4. 可在"照片大小"选择小/中/大
5. 点击"移除"可删除照片

### 3. 切换模板

点击顶部工具栏的"经典模板"按钮，可在经典、现代、创意三种模板之间切换。

- **经典**：传统简历布局，标题在左侧
- **现代**：侧边栏布局，联系方式在左侧
- **创意**：简约现代风格，姓名和职位在同一行

### 4. 调整字体和排版

在"字体设置"栏目中可调整：

- **正文字体**：思源黑体、思源宋体、霞鹜文楷等
- **标题字体**：Bitter、思源宋体等
- **正文字号**：小到特大共 6 档
- **姓名字号**：小到大共 5 档
- **标题字号**：小到大共 5 档
- **行高**：紧凑到宽松共 5 档

### 5. 使用 AI 助手

1. 点击顶部工具栏的"AI 助手"按钮，打开 AI 面板
2. 首次使用需点击齿轮图标，配置 API 地址、API Key、模型
3. 在输入框中描述你的经历，AI 会生成相应内容
4. AI 支持三种快捷操作：
   - **生成**：根据描述生成简历内容
   - **优化**：优化已有内容的表达
   - **诊断**：检查简历的完整性和问题
5. AI 会自动调用工具修改简历数据，更改会实时反映在预览中

### 6. 存档管理

1. 点击顶部工具栏的"存档"按钮，打开存档管理弹窗
2. **保存**：将当前内容保存到当前存档
3. **另存为**：以新名称保存当前内容
4. **加载**：点击已有存档名称即可加载
5. **重命名**：双击或点击编辑按钮可重命名存档
6. **删除**：点击删除按钮可删除存档

### 7. 导出 PDF

点击顶部工具栏的"导出 PDF"按钮：

1. 浏览器会打开一个新标签页，显示简历的完整渲染
2. 新标签页加载完成后会自动弹出打印对话框
3. 在打印对话框中选择"另存为 PDF"
4. 建议打印设置：
   - 目标：另存为 PDF
   - 布局：纵向
   - 纸张大小：A4
   - 边距：无
   - 缩放：默认

### 8. 预览操作

右侧预览区域支持：

- **缩放滑块**：拖拽调整预览大小（30% - 150%）
- **适应窗口**：一键让页面适应预览区域
- **实际大小**：100% 比例查看
- **平移查看**：当预览页面超出可视区域时，可在预览区域内拖拽平移

## 技术栈

- 纯原生 JavaScript，无任何框架依赖
- CSS 自定义属性实现主题和响应式
- localStorage 实现数据持久化
- Canvas 实现照片压缩
- 打印 API 实现 PDF 导出
- OpenAI 兼容接口接入 AI 能力
